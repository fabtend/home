fab0

A pipeline driver and the record of its runs.

A pipeline is a state machine you write as code. fab0 holds each run's state, calls each step at an endpoint you own, moves the run on the signals your people, agents and GitHub send, and keeps the record of every run. It decides nothing for you.

fab0 is a product of fabtend.
